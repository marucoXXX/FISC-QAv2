Reader N
割当グループ N
ファイル量に応じて動的に追加。上限トークン超過時に Router が自動生成。
answer / source
key_excerpt / confidence
⚠ 各 Reader は互いの結果を参照しない（独立実行）。結果の集約・矛盾解消は次段の Reviewer が担当（Fan-in）。Reader の数は毎回 Router が動的に決定する。
↑ 構造化サマリーのみ Fan-in（ドキュメント全文は渡さない）
🔒　Reviewer へ渡すのは構造化サマリーのみ　—　ドキュメント全文は渡さない（Reviewer メモリ安全設計）
