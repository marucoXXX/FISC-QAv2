openpyxl 正規化・重複排除
02
内部データ
◈ SYSTEM DATA（知識ベース）
ドキュメント全文読み込み
/knowledge_base/ 以下の全ファイルをテキスト化し、メモリに展開（〜10ファイル・RAG不要）
📄 policies/ セキュリティポリシー文書
📋 past_answers/ 過去のアンケート回答実績
🔧 system_docs/ 設計・運用ドキュメント
03
AI処理
⚙ PROCESS
Claude API 呼び出し
「質問リスト ＋ ドキュメント全文」をコンテキストとして送信。各質問に対して回答・根拠・信頼度スコアをJSON形式で生成する
claude-sonnet-4-5 max 200k tokens
回答テキスト 根拠ソース名 confidence 0–100
04
レビュー
↔ REVIEW
回答を確認・修正・承認
回答内容・根拠ドキュメント・信頼度スコアをUIで確認し、必要に応じて編集・承認する。フラグ付き（🚩）の質問は優先レビュー
≥80%　承認推奨 60–79%　要確認 ＜60%　🚩 要修正
回答・根拠・スコアを表示
⚙ PROCESS
レビューUI 提供
質問・AI回答・根拠ドキュメント・信頼度スコアを一覧表示するReact画面を提供。編集内容をリアルタイムに保持する
React FastAPI
05
アウトプット
▼ OUTPUT
回答済みExcelを受け取る
承認済み回答・根拠・信頼度・フラグがすべて記入されたExcelファイルをダウンロードし、FISCへ提出する
completed_answers.xlsx

Excel出力生成
